# Yorimiyu

Локальная ИИ-панель со встроенной SQLite-памятью и графом знаний без Docker, а также исходный код необязательного Graphiti в `vendor/graphiti`.

## Запуск панели на Windows

1. Установите Python 3.10+.
2. Скачайте репозиторий (ZIP или git clone).
3. Дважды нажмите `Yorimiyu.bat`.
4. Панель откроется в браузере на случайном локальном порту (127.0.0.1). Для остановки закройте окно BAT или нажмите Ctrl+C.

Панель содержит локальный REST API, SQLite-память, историю чата, поиск, лексический граф и проверяемые предложения для обучения. Чат работает после настройки доверенного HTTPS LLM. Letta CLI запускается только при явном включении, Graphiti принимает записи вручную через локальный сервер. Граф знаний хранится во встроенной SQLite и не требует Docker, Neo4j или Java. Внешний LLM не запускается автоматически. Подробнее: `docs/unified-ai-setup.md`.

## Graphiti

Исходники: `vendor/graphiti/`. Документация, зависимости, примеры и тесты поставляются вместе с upstream. Лицензия исходников: `vendor/graphiti/LICENSE`.

Перед запуском сервисов необходимо отдельно настроить БД, LLM и защиту API. Не открывайте референсные REST/MCP серверы Graphiti в публичную сеть без аутентификации.

## Надёжность запуска

- Повторный запуск использует существующий локальный сервер после проверки его идентификатора через `/health`.
- Журнал ошибок и запусков: `logs/launch.log` (с ротацией).
- Состояние сервера: `.runtime/dashboard.json`. Если сервер завершился аварийно, устаревшее состояние игнорируется при следующем запуске.
- Для запуска без браузера: `Yorimiyu.bat --no-browser`.
- Встроенный Python **не поставляется** в репозитории: можно самостоятельно разместить проверенный Python 3.10+ в `.runtime/python/python.exe`. Автоматической загрузки бинарников нет.
- Обновление приложения и резервное копирование данных Graphiti пока не реализованы. Наличие статического сайта не означает запуск графовой БД.


## Если Yorimiyu.bat не запускается

BAT последовательно проверяет переносной `.runtime\\python\\python.exe`, затем `py.exe -3`, затем `python.exe`. Неисправный первый интерпретатор не блокирует проверку остальных. Требуется Python 3.10+ со стандартными модулями `sqlite3` и `ssl`.

Запустите `Yorimiyu.bat` двойным нажатием. При ошибке окно остаётся открытым; сохраните текст ошибки. Если Python уже начал работу, проверьте `logs/launch.log`. Для проверки Python в CMD: `py -3 --version` и `python --version`.

Если окно закрывается сразу, откройте CMD в папке проекта и запустите `Yorimiyu.bat --no-browser`. Не запускайте BAT из ZIP без распаковки всей папки. Проект должен иметь доступ на запись в `.runtime` и `logs`.


### Автоматическая установка Python в Windows

Если подходящий Python 3.10+ отсутствует, `Yorimiyu.bat` автоматически загружает **официальный встраиваемый Python 3.11.9** с `www.python.org` в локальную папку `.runtime/python`. Администраторские права не требуются, системный Python и PATH не меняются. Для первого запуска нужен интернет; последующие запуски работают без скачивания. При ошибке окно остаётся открытым, а подробности находятся в `.runtime/python-install.log`. Для скачивания используется Windows PowerShell; если политика или антивирус блокируют установку, разрешите загрузку с официального python.org либо установите Python вручную. Автоматическая установка не запускает `pip` и не устанавливает сторонние пакеты.


## Граф знаний без Docker (v0.4.1)

- Граф сущностей хранится в `data/knowledge-graph.sqlite3`, создаётся автоматически при первой индексации или проверке состояния.
- Не нужны Docker Desktop, WSL2, Neo4j, Java, NetworkX или другие сторонние пакеты Python.
- Откройте **Подключения → Индексировать память в SQLite**, чтобы проиндексировать существующие записи. Новые записи также индексируются при сохранении.
- Веб-интерфейс использует `/api/sqlite-graph/graph`, `/api/sqlite-graph/index`, `/api/sqlite-graph/status`. Старые пути `/api/neo4j/*` временно сохранены как совместимые псевдонимы; Neo4j при этом не запускается.
- Ранее созданные данные Neo4j не удаляются автоматически. Если они нужны, экспортируйте их до удаления Docker. Существующая SQLite-память остаётся основным источником данных.
- Резервные копии в интерфейсе охватывают основную SQLite-базу; графовый индекс является производным и после восстановления памяти должен быть перестроен повторной индексацией.
- Опциональный upstream Graphiti в `vendor/graphiti` не запускается автоматически и может иметь собственные требования к серверу и БД.
