# Yorimiyu

Локальная веб-панель в чёрно-золотом оформлении и полный исходный код Graphiti в `vendor/graphiti`.

## Запуск панели на Windows

1. Установите Python 3.10+.
2. Скачайте репозиторий (ZIP или git clone).
3. Дважды нажмите `Yorimiyu.bat`.
4. Панель откроется в браузере на случайном локальном порту (127.0.0.1). Для остановки закройте окно BAT или нажмите Ctrl+C.

Панель **пока статическая**: не подключена к Graphiti, не запускает REST API, MCP или графовую БД. Счётчики и граф не подменяются фиктивными данными. Ключи API не требуются.

## Graphiti

Исходники: `vendor/graphiti/`. Документация, зависимости, примеры и тесты поставляются вместе с upstream. Лицензия исходников: `vendor/graphiti/LICENSE`.

Перед запуском сервисов необходимо отдельно настроить БД, LLM и защиту API. Не открывайте референсные REST/MCP серверы Graphiti в публичную сеть без аутентификации.
