# Безопасный этап подключения Graphiti

После записи памяти в SQLite создаётся событие в `graphiti_outbox` с уникальным `memory_id`. Это позволяет впоследствии отправлять события в Graphiti с повторными попытками, не теряя исходный текст.

`GET /api/graphiti/status` проверяет локальный OpenAPI endpoint Graphiti (только при заданном `YORIMIYU_GRAPHITI_URL=http://127.0.0.1:8000`). `GET /api/graphiti/outbox` показывает ожидающие события. **Автоматическая отправка в Graphiti намеренно не включена**, пока не определены API-схема, подтверждение успешной записи и политика дедупликации; иначе возможна потеря или дублирование фактов.

Нельзя открывать референсный Graphiti сервер во внешнюю сеть: он не имеет авторизации. Letta Code остаётся отдельным runtime; запуск агентов из браузера ещё не реализован.
