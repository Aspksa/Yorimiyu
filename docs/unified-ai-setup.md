# Yorimiyu — единая ИИ-система (проверяемые возможности)

## Что уже работает в коде
- SQLite: агенты, записи памяти, история чата, предложения знаний, очередь Graphiti.
- Локальный поиск по памяти (LIKE), граф лексического сходства, ручное одобрение знаний из сообщений с префиксом «Запомни:».
- OpenAI-compatible Chat Completions API по HTTPS, если указан внешний провайдер.
- Привязка локального профиля к ID агента Letta и ручной вызов Letta CLI.
- Ручная передача одной записи Graphiti с ответом HTTP 202 (принято в очередь, **не подтверждена индексация**).

## Переменные окружения
`YORIMIYU_LLM_URL=https://your-trusted-provider.example/v1`
`YORIMIYU_LLM_MODEL=your-model-id`
`YORIMIYU_LLM_API_KEY=your-secret`
`YORIMIYU_GRAPHITI_URL=http://127.0.0.1:8000`
`YORIMIYU_LETTA_COMMAND=letta`
`YORIMIYU_ENABLE_LETTA_EXEC=1` (включать только после оценки разрешений инструментов Letta)

Никакие секреты не должны попадать в git. Переменные задаются в окружении процесса BAT или в защищённом менеджере секретов. Нельзя вводить их в веб-форму проекта.

## Ограничения
1. Graphiti reference server требует отдельной графовой БД, LLM и embeddings. Сервер без авторизации должен оставаться локальным.
2. Состояние Letta Code и его инструменты зависят от локальной установки и конфигурации. Веб-интерфейс не устанавливает Letta автоматически.
3. Лексический граф — не Graphiti, не извлечение сущностей. Никаких выдуманных связей и фактов.
4. Саморазвитие пока означает **проверяемые пользователем предложения памяти**, а не автоматическое переобучение весов модели.
5. HTTPS LLM endpoint должен быть доверенным: содержимое диалога и найденные фрагменты памяти отправляются провайдеру. Не включайте для конфиденциальных данных без оценки политики сервиса.
6. Протокол Letta CLI может отличаться по версиям. Проверьте `letta --help` и разрешения до включения `YORIMIYU_ENABLE_LETTA_EXEC`.
7. Локальные тесты не заменяют интеграционные проверки с реальными Letta, Graphiti и провайдером модели.
